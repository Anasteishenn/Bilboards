# Руководство пользователя AdBoard

AdBoard — консольная система бронирования рекламных щитов. Все примеры ниже — настоящий вывод
программы (сеансы записаны на чистой базе; введённые значения показаны после приглашений).
Повторяющиеся меню между шагами опущены.

## 1. Запуск

```bash
cmake -S . -B build
cmake --build build
./build/adboard
```

* Запускайте программу **из корня проекта** — рядом должна быть папка `data/` со скриптом `schema.sql`.
* При первом запуске создаётся база `data/adboard.db` с тестовыми данными: три щита и пользователи
  `admin`, `manager`, `client` (пароль совпадает с логином). Данные сохраняются между запусками;
  чтобы начать заново, удалите `data/adboard.db`.
* В Windows программа сама переключает консоль в UTF-8. Для корректного ввода кириллицы удобнее
  Windows Terminal.

## 2. Общие правила ввода

| Что вводится | Формат | Пример |
|---|---|---|
| Пункт меню | номер пункта | `1` |
| Дата | `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД` | `10.10.2026` |
| Сумма | число, дробная часть через точку или запятую | `40,5` |
| Подтверждение | `y` / `n` (или `д` / `н`) | `y` |

Некорректный ввод не завершает программу: она объясняет ошибку и повторяет вопрос.
Выход — пункт `0` главного меню (или `Ctrl+Z` / `Ctrl+D`).

```
Выберите действие: abc
  [!] Ошибка ввода. Введите целое число от 0 до 2.
Выберите действие: 7
  [!] Ошибка ввода. Введите целое число от 0 до 2.
```

## 3. Главное меню: регистрация и вход

```
============================================
   СИСТЕМА БРОНИРОВАНИЯ ЩИТОВ ADBOARD CORE  
============================================
  1. Вход в систему
  2. Регистрация нового клиента
  0. Выход
--------------------------------------------
Выберите действие: 2

--- Регистрация клиента ---
  Логин: 3–32 символа (латиница, цифры, '_' и '.'), пароль — не менее 4 символов.
Придумайте логин: vector_llc
Придумайте пароль: secret1
Повторите пароль: secret1
Контактные данные (телефон/email): +375291112233

[ОК] Регистрация успешно завершена! Вы вошли как vector_llc.
```

После регистрации или входа открывается меню, соответствующее роли пользователя. При неверном пароле:

```
--- Авторизация ---
Логин: vector_llc
Пароль: wrong

[!] Неверный логин или пароль.
```

## 4. Клиент

```
============================================
   ЛИЧНЫЙ КАБИНЕТ КЛИЕНТА (vector_llc)
============================================
  1. Просмотреть весь каталог щитов
  2. Поиск и фильтрация щитов (район / тип / бюджет)
  3. Оформить заявку на бронирование
  4. Мои заявки и статусы договоров
  0. Выйти из аккаунта
--------------------------------------------
```

### 4.1. Каталог

```
Выберите пункт меню: 1

|  ID  | Адрес                     | Район           | Тип экрана  | Размер| Цена (сутки) |
+------+---------------------------+-----------------+-------------+-------+--------------+
|    1 | пр. Независимости, 4      | Московский      | Digital     | 6x3   |    60.00 BYN |
|    2 | пр. Партизанский, 12      | Ленинский       | Static      | 6x3   |    40.00 BYN |
|    3 | ул. Притыцкого, 48        | Фрунзенский     | Prismatron  | 6x3   |    50.00 BYN |
+------+---------------------------+-----------------+-------------+-------+--------------+
```

Списанные администратором щиты в каталоге не показываются.

### 4.2. Фильтрация

Район можно вводить частично и в любом регистре; `-` — любой район, цена `0` — без ограничения.

```
Выберите пункт меню: 2

--- Фильтрация каталога ---
Введите район или его часть (или '-' для любого): моск
  Тип экрана: 1. Static  2. Digital  3. Prismatron  0. Любой
Ваш выбор: 0
Максимальная цена за сутки, BYN (0 — без ограничения): 70

+------+---------------------------+-----------------+-------------+-------+--------------+
|  ID  | Адрес                     | Район           | Тип экрана  | Размер| Цена (сутки) |
+------+---------------------------+-----------------+-------------+-------+--------------+
|    1 | пр. Независимости, 4      | Московский      | Digital     | 6x3   |    60.00 BYN |
+------+---------------------------+-----------------+-------------+-------+--------------+
```

### 4.3. Оформление заявки

Перед созданием заявки программа показывает расчёт стоимости и просит подтверждения.

```
Выберите пункт меню: 3

--- Оформление заявки на аренду ---
Введите ID рекламного щита: 1
Дата начала аренды (ДД.ММ.ГГГГ): 10.10.2026
Дата окончания аренды (ДД.ММ.ГГГГ): 20.10.2026

[Расчёт]:
  - Период: 10.10.2026 – 20.10.2026
  - Длительность: 11 сут.
  - Базовая стоимость: 660.00 BYN
  - Скидка за аренду от 7 суток (5%): -33.00 BYN
  - ИТОГО К ОПЛАТЕ: 627.00 BYN

Подтвердить создание заявки? (y/n): y

[ОК] Заявка #1 успешно создана и отправлена менеджеру!
  Статус: Ожидает подтверждения менеджером
```

**Скидки** (применяется наибольшая, не суммируются): от 7 суток — 5%, от 14 — 10%, от 30 — 15%;
постоянному клиенту (3 и более одобренных заказа) — 10%.

**Оба дня включаются в аренду:** 10–20 октября — это 11 суток.

**Ошибки при оформлении:**

```
Дата начала аренды (ДД.ММ.ГГГГ): 31.02.2026
  [!] Некорректная дата. Формат: ДД.ММ.ГГГГ (например, 10.10.2026).
Дата начала аренды (ДД.ММ.ГГГГ): 2026-10-30
Дата окончания аренды (ДД.ММ.ГГГГ): 25.10.2026

[Отклонено]: Дата окончания раньше даты начала
```

Если даты пересекаются с уже **одобренной** заявкой на этот щит:

```
Введите ID рекламного щита: 1
Дата начала аренды (ДД.ММ.ГГГГ): 08.10.2026
Дата окончания аренды (ДД.ММ.ГГГГ): 15.10.2026

[Отклонено]: Щит #1 уже занят с 10.10.2026 по 20.10.2026
```

Ответ `n` на вопрос о подтверждении отменяет заявку: `[i] Заявка не создана.`

### 4.4. Мои заявки

```
Выберите пункт меню: 4

+--------+----------+-------------------------+--------------+------------+
| Заказ  | ID Щита  | Период аренды           | Сумма (BYN)  | Статус     |
+--------+----------+-------------------------+--------------+------------+
| #1     | 1        | 10.10.2026 – 20.10.2026 |       627.00 | Ожидает    |
+--------+----------+-------------------------+--------------+------------+
```

Статусы: **Ожидает** (на рассмотрении у менеджера), **Одобрена** (даты закреплены за клиентом),
**Отклонена**.

## 5. Менеджер

Вход: `manager` / `manager`.

```
============================================
   ПАНЕЛЬ МЕНЕДЖЕРА (manager)
============================================
  1. Список заявок на рассмотрении (Pending)
  2. Одобрить или отклонить заявку
  3. Отчет по занятости и выручке
  4. Все заявки
  0. Выйти из аккаунта
--------------------------------------------
```

### 5.1. Модерация заявки

Пункт 2 сначала показывает очередь, затем запрашивает номер заявки и решение.

```
Выберите действие: 2

--- ОЧЕРЕДЬ ЗАЯВОК НА БРОНИРОВАНИЕ ---
+--------+----------+----------+-------------------------+--------------+------------+
| Заказ  | Клиент   | ID Щита  | Период аренды           | Сумма (BYN)  | Статус     |
+--------+----------+----------+-------------------------+--------------+------------+
| #1     | ID:4     | 1        | 10.10.2026 – 20.10.2026 |       627.00 | Ожидает    |
+--------+----------+----------+-------------------------+--------------+------------+

--- Модерация заявки ---
Введите номер заказа (ID, 0 — назад): 1
  1. Одобрить заявку (Approve)
  2. Отклонить заявку (Reject)
  0. Отмена
Ваше решение: 1

[ОК] Заявка #1 одобрена. Щит на выбранные даты заблокирован для других клиентов.
```

Решение по заявке принимается один раз. Если пока заявка ждала, те же даты щита уже одобрили
другому клиенту, система не даст одобрить вторую и сообщит, что щит занят.

### 5.2. Отчёт по занятости и выручке

```
Выберите действие: 3

--- Отчёт по занятости и выручке ---
Начало периода отчёта (ДД.ММ.ГГГГ): 01.10.2026
Конец периода отчёта (ДД.ММ.ГГГГ): 31.10.2026

  Период: 01.10.2026 – 31.10.2026 (31 сут.)
+------+---------------------------+-----------------+---------+-----------+--------------+---------+
|  ID  | Адрес                     | Район           | Занято  | Загрузка  | Выручка, BYN | Заявок  |
+------+---------------------------+-----------------+---------+-----------+--------------+---------+
|    1 | пр. Независимости, 4      | Московский      |  11 дн. |   35.50 % |       627.00 |       0 |
|    2 | пр. Партизанский, 12      | Ленинский       |   0 дн. |    0.00 % |         0.00 |       0 |
|    3 | ул. Притыцкого, 48        | Фрунзенский     |   0 дн. |    0.00 % |         0.00 |       0 |
+------+---------------------------+-----------------+---------+-----------+--------------+---------+
  Всего конструкций     : 3
  Средняя загрузка      : 11.83 %
  Выручка за период     : 627.00 BYN
  Заявок на рассмотрении: 0
```

* **Занято** — дни внутри периода, занятые одобренными заявками.
* **Загрузка** — занятые дни / дни в периоде.
* **Выручка** — сумма одобренных заявок, пересекающих период.
* **Заявок** — заявки на этот щит, ожидающие решения.

## 6. Администратор

Вход: `admin` / `admin`. Кроме управления инвентарём, администратору доступны функции менеджера (пункты 5–7).

```
============================================
   ПАНЕЛЬ АДМИНИСТРАТОРА (admin)
============================================
  1. Весь инвентарь (включая списанные)
  2. Добавить рекламную конструкцию
  3. Редактировать конструкцию
  4. Списать (деактивировать) конструкцию
  --- функции менеджера ---
  5. Заявки на рассмотрении
  6. Одобрить или отклонить заявку
  7. Отчет по занятости и выручке
  0. Выйти из аккаунта
--------------------------------------------
```

### 6.1. Добавление конструкции

```
--- Новая рекламная конструкция ---
Адрес: ул. Немига, 14
Район: Центральный
  Тип экрана: 1. Static  2. Digital  3. Prismatron
Ваш выбор: 1
Размер (например, 6x3): 6x3
Базовая ставка за сутки, BYN: 40,5

[ОК] Конструкция добавлена в каталог.
```

### 6.2. Редактирование

Пустой ввод (Enter) оставляет текущее значение, оно показано в квадратных скобках.

```
--- Редактирование конструкции ---
ID конструкции: 3
  Пустой ввод (Enter) оставляет текущее значение.
Адрес [ул. Притыцкого, 48]: 
Район [Фрунзенский]: 
Изменить тип экрана [Prismatron]? (y/n): n
Размер [6x3]: 
Изменить ставку [50.00 BYN]? (y/n): y
Новая ставка за сутки, BYN: 55

[ОК] Конструкция #3 обновлена.
```

### 6.3. Списание и просмотр инвентаря

```
--- Списание конструкции ---
ID конструкции: 2
Списать конструкцию #2? Она пропадёт из каталога (y/n): y

[ОК] Конструкция #2 списана.

Выберите действие: 1

+------+---------------------------+-----------------+-------------+-------+--------------+-----------+
|  ID  | Адрес                     | Район           | Тип экрана  | Размер| Цена (сутки) | Статус    |
+------+---------------------------+-----------------+-------------+-------+--------------+-----------+
|    1 | пр. Независимости, 4      | Московский      | Digital     | 6x3   |    60.00 BYN | Активен   |
|    2 | пр. Партизанский, 12      | Ленинский       | Static      | 6x3   |    40.00 BYN | Списан    |
|    3 | ул. Притыцкого, 48        | Фрунзенский     | Prismatron  | 6x3   |    55.00 BYN | Активен   |
|    4 | ул. Немига, 14            | Центральный     | Static      | 6x3   |    40.50 BYN | Активен   |
+------+---------------------------+-----------------+-------------+-------+--------------+-----------+
```

Списанный щит остаётся в базе (его история заказов сохраняется), но исчезает из каталога клиента
и не может быть забронирован.

## 7. Сохранение данных

Все изменения сразу записываются в `data/adboard.db`. После перезапуска программы клиент видит
актуальный статус своей заявки:

```
Логин: vector_llc
Пароль: secret1

[ОК] Добро пожаловать, vector_llc!
...
Выберите пункт меню: 4

+--------+----------+-------------------------+--------------+------------+
| Заказ  | ID Щита  | Период аренды           | Сумма (BYN)  | Статус     |
+--------+----------+-------------------------+--------------+------------+
| #1     | 1        | 10.10.2026 – 20.10.2026 |       627.00 | Одобрена   |
+--------+----------+-------------------------+--------------+------------+
```

## 8. Возможные проблемы

| Симптом | Причина и решение |
|---|---|
| `[КРИТИЧЕСКИЙ СБОЙ СИСТЕМЫ]: не удалось открыть базу данных…` | Программа запущена не из корня проекта: перейдите в папку, где лежит `data/`. |
| Под `admin` / `manager` / `client` не входит | Осталась старая `data/adboard.db` с заглушками паролей — удалите её, база создастся заново. |
| Вместо кириллицы «кракозябры» | Используйте Windows Terminal или PowerShell 7; программа включает UTF-8 сама. |
| Windows не даёт запустить `adboard.exe` | Сработала защита Smart App Control / антивирус для только что собранного файла. Разрешите запуск в настройках безопасности или запустите на другом компьютере. |
